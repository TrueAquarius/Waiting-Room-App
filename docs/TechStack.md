# Waiting Room Application — Technology Stack (Proposal)

This is a **proposal** for the technology stack of the Waiting Room Application. The functional requirements are defined in [Requirements.md](Requirements.md).


## Runtime / Server

| Concern | Recommendation | Why |
|--------|---------------|-----|
| Runtime | **Node.js (LTS)** | Required. |
| Language | **TypeScript** (strict) | Required. Type safety for the small domain model. |
